## Suggested file format

- **Photos:** PNG or JPG. Keep under 2 MB each.
- **Screenshots:** PNG. Use ⌘+Shift+4 to capture a region cleanly.
- **Annotations:** Preview's Markup tool works well for arrows and circles —
  use the saffron/amber color from the design system if possible.
